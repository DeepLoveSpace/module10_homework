Репозиторий содержит три независимых практических заданий.

1. `svg_toggle_button` - Кнопка-переключатель SVG.
Кнопка, которая при клике меняет одну SVG-иконку на другую и обратно.

2. `screen_size_alert` - Вывод размеров экрана.
Кнопка, которая при клике вызывает системное окно `alert` с данными о размерах окна и экрана.

3. `echo_chat` — Чат с эхо-сервером и геолокацией.
Веб-чат, работающий через WebSocket. Сервер возвращает отправленные сообщения (эхо). И при отправке геолокации данные уходят на сервер а в чат выводится кликабельная ссылка на OpenStreetMap с координатами пользователя.
